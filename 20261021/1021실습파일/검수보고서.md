# Day3 실습자료 검수보고서

## 대상과 기준
- 강의: 2026.10.21 수요일 · AI 개발을 위한 Python 데이터 처리 기초 Day3.
- 기준 PPT: 89장, 실습 01~08의 3단계 요구사항 및 프로젝트 제출 기준.
- 과제: 8개 주제 × 기본필수/응용/심화 = 24개 독립 단계.
- 수강생 구현 지점: 59개 TODO 블록. 강사의 같은 번호 해설과 대응.

## 실제 실행 환경
Python 3.13.5 / NumPy 2.3.5 / pandas 2.2.3 / Linux.
Python 파일: 강사용 108개 + 수강생용 108개 = 216개 (검사·런처 포함).
Windows와 macOS에서 직접 실행한 검증은 하지 않았습니다. 해당 환경의 경로·실행 안내를 제공합니다.
실제 GitHub 계정·커밋·PR 작업은 수행하지 않았습니다. 온라인 안내와 오프라인 대체 활동을 제공합니다.

## 자동 검증의 한계
275는 테스트 메서드 수이며 일부 메서드는 여러 하위 입력을 추가로 확인합니다. 모든 가능한 입력·운영환경의 무결함을 뜻하지 않습니다.
GitHub 활동·리뷰의 질·개인 기여는 기록지를 근거로 사람이 확인합니다. 자동 검사만으로 이를 완료 처리하지 않습니다.
기본필수도 공통 평가 기준 100점이 가능하고 확장 기능은 별도 평가합니다.
review_target.py 및 공유 상태 재현 클래스는 의도적 결함 예제입니다. Agent.run의 NotImplementedError는 추상 계약입니다.
수강생 TODO의 NotImplementedError는 정상적인 미완성 표시이며 기능 완료 후 제거합니다.

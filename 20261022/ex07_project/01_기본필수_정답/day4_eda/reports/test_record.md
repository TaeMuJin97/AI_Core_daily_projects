# 강사용 프로젝트 독립 테스트 기록

프로젝트 폴더만 별도의 임시 위치로 복사하고 `python -m unittest discover -s tests -v`를 실행했습니다. **4건 모두 통과**했습니다.

| 분류 | 입력·상황 | 기대 결과 | 실제 결과 |
|---|---|---|---|
| 정상 | 원본 13행 | 정제 12행, 요약 3행 | 통과 |
| 경계 | latency 전체 결측 | 측정 수 0, 평균 결측, 정상 실행 | 통과 |
| 실패 | 같은 ID에 서로 다른 값 | 오류 안내, 기존 결과 보존 | 통과 |
| 실패 | 완전히 빈 입력 | 빈 분석으로 위장하지 않고 중단 | 통과 |

위 기록은 강사용 자료의 제작 검수입니다. 수강생의 실제 실행·개인 기여·동료 리뷰를 확인한 기록은 아닙니다. 전체 로그는 강사용 역할 폴더의 `reports/demo_runs.json`에 있습니다.

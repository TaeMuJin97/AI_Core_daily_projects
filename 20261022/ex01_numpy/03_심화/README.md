# 실습 01 · 배열 보정과 안전한 집계 · 심화

**PPT 12쪽 / 20분 / 수강생용**

## 목표·입력
a=[[100,300,200],[120,500,250]], 열 계수 [1.0,0.8,1.1], 행 계수 [1.0,0.5]. 단위 ms.

## 완료 기준
열 평균 [110,400,225], 행 평균 [200,290]. 유효 수 2, 평균 200. 0/0 비율은 NaN(JSON 기록에는 null).

## 진행
기본필수부터 수행하고 선택 확장합니다. 같은 단계의 제공 코드는 경로·읽기·이전 단원 재사용을 위한 것으로, 직접 완성할 부분은 아래 TODO입니다. 난이도별로 다른 독립 시작점을 제공하므로 앞 과제의 미완성 때문에 다음 과제가 막히지 않습니다. 07과 08은 같은 프로젝트를 계속 사용합니다.

## 구현 위치와 힌트
- `N_SHAPE`: a는 2차원, col은 (열 수,), row는 (행 수,)인지 검사하고 아니면 ValueError. 유한한 값만 허용합니다.
- `N_VALID`: isfinite와 >=0 조건을 &로 결합. 잘못된 값은 NaN, 유효 수를 세고 0건이면 평균도 NaN으로 반환하세요.
- `N_RATE`: NaN float 배열을 만든 뒤 np.divide(..., out=..., where=total>0)로 계산해 반환하세요.

## 함수 계약
함수 위 docstring의 매개변수·반환값·오류 조건을 따릅니다. 반환 형식을 바꾸기보다 계산을 채웁니다. `NotImplementedError`는 의도적인 미완성 표시이며 문법 오류가 아닙니다. 정답의 결과는 expected_output.txt/expected_outputs에 제공하되 검사 기준 자체를 수정하지 않습니다.

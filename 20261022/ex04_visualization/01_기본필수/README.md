# 실습 04 · 비교·분포·관계 시각화 · 기본필수

**PPT 43쪽 / 25분 / 수강생용**

## 목표·입력
data/clean_runs.csv, data/summary.json을 재사용한다. 각 함수는 Figure 한 개씩 생성한다.

## 완료 기준
막대·히스토그램PNG 필수. histogram [3,4,1,0,1], 산점도9행. 날짜별245ms라도 유효/전체는6/6과2/5로 다르다.

## 진행
기본필수부터 수행하고 선택 확장합니다. 같은 단계의 제공 코드는 경로·읽기·이전 단원 재사용을 위한 것으로, 직접 완성할 부분은 아래 TODO입니다. 난이도별로 다른 독립 시작점을 제공하므로 앞 과제의 미완성 때문에 다음 과제가 막히지 않습니다. 07과 08은 같은 프로젝트를 계속 사용합니다.

## 구현 위치와 힌트
- `P_BAR`: summary로 막대를 그리고 0 기준선·단위·역할별 측정/전체 수를 표시하세요. 측정 0건은 0ms가 아니라 No measurement로 안내하세요.
- `P_HIST`: latency 결측만 제외한 values를 만들고 0~1000의 200 간격 bins를 사용하세요. 범위가 커지면 확장. counts, edges를 받고 제목에 n을 표시하세요.

## 함수 계약
함수 위 docstring의 매개변수·반환값·오류 조건을 따릅니다. 반환 형식을 바꾸기보다 계산을 채웁니다. `NotImplementedError`는 의도적인 미완성 표시이며 문법 오류가 아닙니다. 정답의 결과는 expected_output.txt/expected_outputs에 제공하되 검사 기준 자체를 수정하지 않습니다.

## 실행·검사 (역할 폴더에서)
```text
python tools/run.py --exercise 04 --level basic
python tools/check.py --exercise 04 --level basic
```
직접 실행 파일: `ex04_plot.py`. 실행 위치가 달라도 파일 위치를 기준으로 data/out을 찾습니다. 검사는 임시 복사본에서 이루어져 본인의 결과를 바꾸지 않습니다.

## 그림 검수
축은 호환성을 위해 영문으로 제공합니다. 한글설명은 해석기록에 작성합니다. 글꼴파일은 제공하지 않습니다. 설치된한글글꼴을 선택할 수도 있습니다. `out/charts` 이미지를 실제로 열고 숫자·단위·n을 확인합니다. 산점도는 두 수치가 모두 있는9건, 날짜미상1건은 선그래프에서 임의날짜에 넣지 않습니다.

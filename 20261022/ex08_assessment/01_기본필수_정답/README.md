# 실습 08 · 최종 검증·보고서·제출 · 기본필수

**PPT 75쪽 / 35분 / 강사용**

## 목표·입력
07에서 완성한 같은 프로젝트를 검사한다. 새 프로젝트나 Git 저장소를 다시 만들지 않는다.

## 완료 기준
코드·결과·보고서·테스트 기록·목적 있는 Git 커밋을 제출. 자동 통과와 강사 채점은 다르다. 기본필수만으로 100점 가능.

## 진행
기본필수부터 수행하고 선택 확장합니다. 같은 단계의 제공 코드는 경로·읽기·이전 단원 재사용을 위한 것으로, 직접 완성할 부분은 아래 TODO입니다. 난이도별로 다른 독립 시작점을 제공하므로 앞 과제의 미완성 때문에 다음 과제가 막히지 않습니다. 07과 08은 같은 프로젝트를 계속 사용합니다.

## 구현 위치와 힌트
- `V_TABLES`: 제공된 검사 흐름 안에서 part와 values로 expected 사전만 계산합니다. 전체 수·측정 수·평균·중앙값·성공률·백분율을 채우세요. 필수 열 검사와 실제 비교 코드는 제공됩니다.

## 함수 계약
함수 위 docstring의 매개변수·반환값·오류 조건을 따릅니다. 반환 형식을 바꾸기보다 계산을 채웁니다. `NotImplementedError`는 의도적인 미완성 표시이며 문법 오류가 아닙니다. 정답의 결과는 expected_output.txt/expected_outputs에 제공하되 검사 기준 자체를 수정하지 않습니다.

## 실제 제출검사
같은 난이도 실습 07의  day4_eda에서 먼저 main.py를 실행하고 보고서를 작성합니다.
```text
python tools/run.py --exercise 08 --level basic
python tools/check.py --exercise 08 --level basic
python tools/check_git.py --project "ex07_project/01_기본필수/day4_eda" --level basic
```
run은 본인 프로젝트를 읽기만 합니다. check는 작성한 검증함수를 테스트하며, 본인 Git 활동·보고서 품질의 최종 승인을 뜻하지 않습니다. 제출경로는 강사가 현장에서 안내합니다.

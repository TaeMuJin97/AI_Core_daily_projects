# 강사용 실행 검수 기록 · 실습 08 / basic

아래는 자료 제작 과정에서 **강사용 정답을 실제 실행한 기록**입니다. 수강생 본인의 수행·리뷰 기록과는 구분합니다.

실행한 자동 테스트 8건 / 실패 0건 / 오류 0건 / 건너뜀 0건입니다. 압축 해제한 폴더에서도 다시 통과했습니다.

짝에게 입력·출력, 결측 정책, 분모, 원본 보존 이유를 설명하게 하세요. 수강생의 미실시 활동을 이 기록으로 대체하지 않습니다.

# Git 명령 뒤에 확인할 상태

커밋 해시·시각·작성자 정보는 실행마다 달라집니다. 고정 문자열 대신 아래 의미를 확인합니다.

| 시점 | 예상 상태 |
|---|---|
| init 직후 | 현재 브랜치 main, 아직 커밋 없음 |
| 첫 커밋 후 | README.md와 .gitignore가 추적됨. 나머지 제공 소스는 `??`로 남을 수 있음 |
| 두 번째 커밋 후 | 실제 README 변경을 포함한 커밋이 2개 이상 |
| `git branch feature/eda` 뒤 | 새 브랜치가 생기지만 현재 브랜치는 여전히 main |
| `git switch feature/eda` 뒤 | 현재 브랜치가 feature/eda |
| add 뒤 같은 파일 재수정 | `MM` 상태. cached diff는 첫 변경, 일반 diff는 그 이후 변경 |
| 위 상태에서 commit | 스테이징된 변경까지만 포함됨. 나중 변경은 작업 폴더에 남음 |
| 최종 제출 전 | 필요한 소스와 보고서를 추적하고 나머지 파일의 포함·제외 이유를 설명함 |

기본필수는 두 커밋까지, 응용은 브랜치 생성·이동까지, 심화는 두 변경의 차이까지 확인합니다. 단순히 커밋 개수만 채우는 빈 커밋은 완료로 인정하지 않습니다.

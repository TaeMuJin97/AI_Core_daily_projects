[전체 안내](../README.md) · 수강생용

**기존에 승인한 Python 파일 7개와 CSV는 수정하지 않았습니다.** 새로 추가한 것은 이 README입니다. TODO 9곳만 완성하고, 8교시는 07번을 다시 실행합니다.

## 시작하기

ZIP을 모두 풀고 VS Code에서 `수강생용/01_기본필수` 폴더를 엽니다. 기존 수업 Python 실행기를 선택합니다. 이 README의 명령은 **`01_기본필수` 폴더의 터미널** 기준입니다. 각 파일의 TODO를 수정하고 `Ctrl+S`로 저장한 뒤 실행합니다.

```bash
python 01_xy.py
```

패키지가 없을 때만 강사와 실행기를 확인하고 `python -m pip install -r ../requirements.txt`를 실행합니다. 새 가상환경이나 보조 폴더를 만드는 것은 과제가 아닙니다.

## 파일과 입력


`requests.csv`는 정상 요청 20건입니다. `request_id`는 식별용, `input_chars`는 글자 수, `task_type`은 작업 종류, `failed`는 성공 0 / 실패 1입니다. 결측·중복·잘못된 값은 없습니다. **입력 2열, 분할 12/4/4, 변환 3열**이 이 단계의 기준입니다. PPT의 100행 예제와 다른 수치가 나오는 것이 정상입니다.

기본필수 04~06은 작은 표를 코드 안에서 만듭니다. 앞 실습의 결과 파일 없이 각각 실행됩니다. 새 `def`, `class`, `try/except`나 테스트 코드를 추가하지 않습니다.

| 실습 | 직접 완성할 곳 | 확인할 결과 |
|---|---|---|
| 01 | B01-1·B01-2 | X(20,2), y(20,) |
| 02 | B02-1 | train 평균 15 |
| 03 | B03-1 | train 12 / valid 4 / test 4 |
| 04 | B04-1 | train 평균 200으로 valid 변환 |
| 05 | B05-1 | qa·summary 두 열 |
| 06 | B06-1 | 입력 2열 → 변환 3열 |
| 07 | B07-1·B07-2 | fit·predict와 CSV 생성 |
| 08 | 새 TODO 없음 | 07 재실행·설명 |

> 임시 코드가 정상 종료되어도 완성은 아닙니다. 숫자를 직접 넣지 말고 지정한 연산·메서드를 사용하세요. 07의 학습 자리를 `pass`로 둔 채 예측만 바꾸면 아직 학습되지 않았다는 오류가 날 수 있으므로 두 곳을 함께 완성합니다.

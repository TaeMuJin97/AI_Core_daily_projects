## 실습 01 · 예측 시점과 문제 바꾸기

**목표:** 기존 응용의 분류·회귀 문제 정의를 수행합니다.

**열 파일:** `main.py` · PPT 실습 안내 16쪽

### 진행 순서

1. 분류와 회귀의 정답을 구분합니다.
2. 각 예측 목표를 한 문장으로 적습니다.

```bash
python main.py
```

### 직접 완성할 부분

| TODO | 수행할 일 |
|---|---|
| `H01-1` | 실행시간 회귀에서 예측할 정답을 선택하세요. |

**힌트:** 회귀는 연속적인 실행시간을 예측합니다.

### 예상 출력

완성한 강사용 코드를 실제 실행한 결과입니다. 표시 자리수나 표의 공백보다 값·행 수·열의 의미를 확인합니다.

```text
X: (100, 4)
분류 정답: [1, 0, 0]
회귀 정답(ms): [1994, 1799, 179]
elapsed_ms는 실행 전 입력이 아니라, 실행시간 회귀에서 예측할 정답입니다.
```

**예상 결과 위치:** [expected/console.txt](expected/console.txt). 여기는 참고 파일이며 실행 결과를 덮어쓰는 장소가 아닙니다.

**설명 질문:** elapsed_ms를 무조건 삭제해야 하나요?

**완료 기준:** 지정한 TODO를 실제 연산·메서드 호출로 완성하고, 예상 결과를 재현한 뒤 설명 질문에 답합니다. 출력 숫자를 직접 넣어 결과만 맞추지 않습니다.

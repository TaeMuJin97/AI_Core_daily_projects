## 폴더의 역할

| 이름 | 용도 |
|---|---|
| `README.md` | 목표·파일·직접 완성할 곳·실행·예상 결과·완료 기준 |
| `data/` | 읽기 전용으로 다룰 입력 CSV. 외부 입력이 없는 실습02에는 없음 |
| `expected/` | 정답 실행으로 만든 참고 결과. 프로그램이 입력으로 읽거나 수정하지 않음 |
| `outputs/` | 수강생이 직접 실행하여 만든 결과. 저장 활동인 실습03·프로젝트에만 있음 |
| `reports/` | 종합 프로젝트 결과에 대한 본인의 판단과 설명 |

필요하지 않은 폴더는 빈 형식으로 추가하지 않았습니다. `outputs/`는 처음 비어 있고 실행하면 채워집니다. 각 실습은 이전 결과에 의존하지 않으며 **08 복원만 07을 먼저 실행**해야 합니다.

## 실행 방법

실습 폴더를 VS Code에서 열고 그 폴더의 터미널에서 `python main.py`를 실행합니다. `day5_ml`에서는 `python main.py` 후 별도 명령 `python restore.py`를 실행합니다.

`03_심화` 폴더를 열어 둔 상태라면 아래와 같이 상대경로로 실행해도 됩니다.

```bash

python "day5_ml/main.py"
```

## 데이터와 안전한 저장·복원

| 열 | 의미 | 역할 |
|---|---|---|
| `request_id` | 요청을 구분하는 ID | 결과를 연결할 때 사용, 모델 입력에서는 제외 |
| `input_chars` | 요청 입력의 글자 수 | 입력 X |
| `allowed_tools` | 요청 전에 정한 사용 가능 도구 수 | 입력 X |
| `task_type` | 작업 종류 | 입력 X |
| `priority` | 요청 전에 정한 우선순위 | 입력 X |
| `failed` | 실패 1 / 성공 0 | 분류의 정답 y |
| `status` | 실행이 끝난 뒤의 상태 | 실행 전 예측의 입력에서는 제외 |
| `elapsed_ms` | 실제 실행시간(ms) | 실행 전 입력에서는 제외. 회귀 문제의 정답으로는 사용 가능 |
| `retry_count` | 실행 중 발생한 재시도 수 | 실행 전 입력에서는 제외 |

결측은 대체 방법을 배우기 위해 의도적으로 포함했습니다. 손상된 파일, 중복 ID, 잘못된 데이터 형식 처리 과제는 넣지 않았습니다. `requests.csv`는 원본으로 보관하고, 생성한 결과만 `outputs/`에 저장합니다.

원본·행 순서·seed를 유지합니다. `test`는 ID 소속 기록과 분할 확인 외에 전처리·학습·예측·평가에 사용하지 않습니다. `expected/`를 읽어 결과를 복사하는 방식으로 완료하지 않습니다.

`joblib.load`는 자신의 `main.py`가 같은 환경에서 생성한 `outputs/pipeline.joblib`에만 사용합니다. 출처를 모르는 모델 파일을 열지 않습니다. 배포 ZIP에는 학습된 모델을 넣지 않았습니다. 저장할 때와 다른 라이브러리 버전에서 복원이 된다고 가정하지 않습니다.

추가 읽기: scikit-learn 공식 [누수와 전처리](https://scikit-learn.org/1.8/common_pitfalls.html), [모델 저장·복원의 주의점](https://scikit-learn.org/1.8/model_persistence.html). 모든 문서를 읽는 것은 필수 과제가 아닙니다.

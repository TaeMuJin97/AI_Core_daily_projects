## 0. 첫 실행부터 성공하기

ZIP을 풀고 역할 폴더를 VS Code에서 엽니다. 이 HTML은 읽는 안내서이고 코드는 VS Code에서 수정합니다.
추가 패키지를 설치하지 않습니다. 기존 Python으로 다음 명령을 실행합니다.

```text
python check_env.py
python 00_warmup.py
```

`00_warmup.py`에는 빈칸이 없습니다. 실행 후 `double(3)`의 3만 4로 바꾸어 다시 실행합니다.
출력이 6에서 8로 바뀌는지 확인합니다. 오늘도 이렇게 **작은 변경 한 번 → 실행 한 번**을 반복합니다.

### 반복할 네 동작

**① 값을 예상한다 → ② TODO 하나를 채운다 → ③ 실행·대조한다 → ④ 한 문장으로 설명한다.**

막힌 지점을 기록하고 질문해도 됩니다. 함수 이름·틀·파일 읽기 코드는 제공하며 암기 여부를 검사하지 않습니다.
짝은 코드를 대신 완성하지 않고 “이 함수는 무엇을 받아서 무엇을 돌려주나요?”부터 묻습니다.

# 01 함수 활용

**오전 1~2교시**

**꼭 구분할 것:** 함수를 정의하는 것과 호출하는 것은 다릅니다. `return`은 호출한 곳에 값을 주고,
`print`는 화면에 보여 줍니다. `price`, `quantity`는 함수가 받은 입력입니다.

# 03 CSV·JSON 읽기·정제·집계·저장

**오후 5~6교시**

**하나의 처리 흐름:** 읽기 → 공백/자료형 정리 → 금액 계산 → 합계 → 저장 → 다시 읽기.
먼저 `data/orders_basic.csv`와 `data/orders_basic.json`을 VS Code에서 텍스트로 엽니다.
CSV 3건과 JSON 2건은 서로 다른 거래이므로 연결하면 5건입니다.

| ID | 상품 | 단가 | 수량 | 예상 금액 |
|---|---|---:|---:|---:|
| C01 | 아메리카노 | 3000 | 2 | 6000 |
| C02 | 카페라떼 | 4000 | 1 | 4000 |
| C03 | 쿠키 | 2000 | 3 | 6000 |
| J01 | 아메리카노 | 3000 | 1 | 3000 |
| J02 | 카페라떼 | 4000 | 2 | 8000 |

CSV의 숫자 문자열을 그대로 더하면 원하는 계산이 되지 않습니다.
`int("2")`는 정수 2, `" 쿠키 ".strip()`은 공백이 없는 “쿠키”입니다.
`read_csv`, `read_json`, `save_results`의 파일 열고 닫는 부분은 제공했습니다.
읽기 함수들을 호출하고 정제·집계를 구현하는 데 집중합니다.

**원본 보존:** `data`는 수정하지 않습니다. 새 행을 만들어 `outputs`에 저장합니다.
수량 누락·중복 처리는 응용·심화에서만 다룹니다. 기본필수에서 한꺼번에 해결하지 않습니다.
**기본필수 추가 반복:** 입력 파일 사본에서 한 수량만 바꾸고 결과가 얼마나 달라질지 먼저 적어 봅니다.

# 막혔을 때 — 증상 하나부터

| 증상 | 먼저 볼 곳 | 해볼 일 |
|---|---|---|
| `[아직 작성할 곳]` | 표시된 TODO ID | 한 곳을 완성한 뒤 그 파일만 다시 실행 |
| `None`이 보임 | 함수의 마지막 줄 | print만 하지 않았는지, return이 있는지 확인 |
| 한 주문만 합산됨 | return 들여쓰기 | for문이 끝난 뒤 return이 있는지 확인 |
| 숫자가 이어 붙음 | `type(...)` | int로 바꾼 후 계산 |
| `NameError` | 철자·변수의 위치 | 매개변수인지, self 속성인지 확인 |
| `AttributeError` | `__init__`의 속성 이름 | self.quantity 등 생성한 이름과 같은지 확인 |
| `KeyError` | Dict의 실제 키 | unit_price와 price를 혼동하지 않았는지 확인 |
| `IndentationError` | 줄 앞의 공백 | 함수·for·if의 들여쓰기를 주변 코드와 맞춤 |
| `SyntaxError` | 괄호·따옴표·콜론 | 에러 줄 바로 위도 확인 |
| `FileNotFoundError` | 파일명·압축 해제 | 폴더를 통째로 풀었는지, data를 삭제하지 않았는지 확인 |

**질문할 때:** 실행 명령, 파일명, TODO 번호, 예상값, 실제값(또는 마지막 오류 문장)을 함께 보여 주세요.
5분 넘게 같은 오류라면 혼자 계속 바꾸지 않고 도움을 요청합니다. 본인이 시도한 한 줄을 설명합니다.

## 문법 연결표

| 표현 | 이 실습에서의 의미 |
|---|---|
| `row["quantity"]` | Dictionary의 quantity 값 |
| `order.quantity` | Order 객체에 저장된 quantity 속성 |
| `order.amount()` | Order 객체의 amount 메서드 호출 |
| `return value` | 호출한 쪽에 value 전달 |

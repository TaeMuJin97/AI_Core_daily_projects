## 기존 PPT와 다른 수치

| 기준 | 기본필수 | 응용·심화 |
|---|---|---|
| 입력 CSV | 정상 합성 요청 20건, B001~B020 | 원래 PPT의 합성 요청 100건, R001~R100 |
| 입력 X | 글자 수·작업 종류 2열 | 글자 수·허용 도구 수·작업 종류·우선순위 4열 |
| 분할 | train 12 / valid 4 / test 4 | train 60 / valid 20 / test 20 |
| 공통 자료의 변환 특성 | 3열 | 8열 |
| valid 정확도 | 0.75, 4건 중 3건 일치 | 0.70, 20건 중 14건 일치 |
| 실패 발견 | 실제 실패 1건 중 0건 | 실제 실패 6건 중 0건 |

기본필수는 이미 승인한 쉬운 예제입니다. 기존 PPT의 100행·8열·정확도 0.70을 맞추려고 기본필수 데이터를 바꾸지 않습니다. 원본 PPT의 학습 주제와 실습 번호는 유지하며, 분량·수치·제출 기준은 이 수정판 README를 따릅니다. 두 데이터의 점수를 직접 비교해 어느 모델이 더 좋다고 해석하지 않습니다. 모든 자료는 교육용 합성 자료입니다.

## 환경 준비

이미 수업에서 사용하던 Python 실행기를 선택합니다. 정상 실행되는 환경을 다시 설치하거나 업그레이드할 필요는 없습니다.
VS Code에서 `Ctrl+Shift+P` → `Python: Select Interpreter`로 기존 수업 환경을 선택하고 새 터미널을 엽니다.
패키지 오류가 있을 때만 강사와 확인한 뒤 역할 폴더의 `requirements.txt`로 설치합니다.

```bash
python --version
python -m pip install -r requirements.txt
```

위 설치 명령의 작업 폴더는 `수강생용/` 또는 `강사용/`입니다. `01_기본필수/`나 `02_응용/` 안에서 설치한다면 `python -m pip install -r ../requirements.txt`를 사용합니다.
PowerShell의 가상환경 활성화가 막히면 실행 정책을 무작정 바꾸지 말고 강사와 실행기를 확인하세요. 기존 환경의 `python.exe`를 직접 지정해 실행할 수도 있습니다.

제작 검증 환경: Python 3.13.5 · NumPy 2.3.5 · pandas 2.2.3 · scikit-learn 1.8.0 · joblib 1.5.3 · Linux. 이 버전은 최신 버전 주장이나 업그레이드 권고가 아니라 확인한 조합의 기록입니다. Windows·macOS에서 직접 실행한 검증은 아닙니다.

## 미완성 코드의 의미

학생 파일의 `TODO`에는 임시 값이나 `pass`가 있습니다. 실행이 끝났어도 정답이 아닐 수 있습니다. README의 예상 출력·완료 기준·설명 질문을 함께 확인합니다. 특히 기본필수 07은 학습·예측 TODO 두 곳을 함께 완성합니다.
실행 오류를 잡는 복잡한 예외처리를 작성하는 과제가 아닙니다. 실행기·패키지·파일 위치 문제는 강사에게 확인합니다.

## 필요한 용어

| 표현 | 이번 실습에서의 뜻 |
|---|---|
| `X` / `y` | 예측 전에 넣는 입력 / 나중에 비교할 정답 |
| `shape` | 행·열 개수. `(20, 2)`는 20행 2열 |
| `fit` | 학습 자료에서 기준이나 모델 상태를 배움 |
| `transform` | 이미 학습한 기준으로 자료를 변환함 |
| `predict` | 학습된 모델로 입력의 결과를 예측함 |
| `Pipeline` | 전처리와 모델 등 여러 단계를 순서대로 연결함 |
| `DummyClassifier` | 가장 많은 정답만 반복하는 비교 출발점. 실제 유용한 AI를 완성했다는 뜻이 아님 |
| `pass` | 아무것도 하지 않는 임시 자리. 지정된 TODO에서 실제 문장으로 바꿈 |

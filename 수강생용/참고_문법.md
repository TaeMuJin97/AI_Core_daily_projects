# 제공 문법·규칙 확인

아래는 Python 3.13 공식 문서를 참고해 실습 사용 범위만 정리한 것입니다.

- `input()` 결과는 str이므로 숫자 계산 전에 `int` 또는 `float`로 변환합니다.
- `append`는 기존 List를 변경합니다. `items = items.append(x)`로 쓰지 않습니다.
- `Dict`는 입력된 키의 삽입 순서를 유지합니다. 값의 접근은 숫자 인덱스가 아니라 키를 기준으로 합니다.
- `Set`은 표시 순서를 보장하지 않습니다. 결과를 일정하게 보여주려면 제공된 `sorted`를 사용합니다.
- `range(1,n+1)`에서 끝값 n+1은 제외됩니다. `enumerate(..., start=1)`의 번호는 1부터 시작합니다.
- `return`은 함수 결과를 전달합니다. `print`는 화면 출력이며 둘의 용도는 다릅니다.
- `strip`은 앞뒤 공백만 제거합니다. `split(maxsplit=1)`은 최대 한 번 나누므로 항목 내부의 나머지 문자열을 유지합니다.
- 같은 파일의 기능을 함수로 나누는 것이 오늘의 '모듈형' 설계입니다. .py 파일을 패키지로 분할하는 것은 다음 시간으로 연결합니다.

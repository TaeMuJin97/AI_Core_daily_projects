# 제공 검사 도구

check.py와 cases.json은 동작 확인용이며 수강생이 구현할 파일이 아닙니다.
기대 출력·함수 계약·경계값은 공개되어 있습니다. 정답 알고리즘은 포함하지 않습니다.
--all을 실행하면 아직 수행하지 않은 선택 난이도도 검사하므로 미완성은 FAIL이 됩니다.
실습 00 심화의 환경 경로와 버전은 PC별로 달라 고정 문자열로 비교하지 않습니다. 실제 설치 여부와 설명의 타당성은 강사가 확인합니다.

python tools/check.py --exercise 07 --level advanced
python tools/check.py --all

검사 대상은 신뢰할 수 있는 자신의 실습 코드로 제한하세요. 보안 샌드박스가 아닙니다.

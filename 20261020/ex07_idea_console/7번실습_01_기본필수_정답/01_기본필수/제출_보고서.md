# 강사용 프로젝트 보고서 작성 예 · 실제 개인 기여의 대필 아님

선택 단계: 기본필수

요구사항: ① 이름이 비면 등록 거부 ② 정상 자료 등록 ③ 전체 조회 ④ 0 입력 시 종료.
응용 이상: 검색·난이도 필터·통계·이름 중복 검사. 심화: 역할 List·정리 함수·자동 테스트.

데이터 예시: StudyBot(학습 자료 탐색), PaperMate(논문 요약), DataHelper(표 데이터 안내).
기본필수는 이름 문자열 List, 응용은 Dict 목록, 심화는 Dict 안의 역할 List까지 사용한다.

함수 역할: add_idea는 등록 가능 여부를 검사하고 데이터를 추가한다. format_ideas는 읽은 결과를 문자열로 만든다. main은 입력과 출력·종료를 연결한다.

테스트 예: 빈 목록→등록된 아이디어가 없습니다.; 이름 공백→등록 거부; 3건 등록 후 목록→1~3 순번; 0→종료.
응용 이상에서 StudyBot과 ' studybot ' 중복 거부, 잘못된 난이도 거부, 검색 결과 없음, 빈 통계 0도 확인한다.

자동 검수 결과는 별도 검수 보고서와 실제 실행 출력에 있다. 수강생의 실제 실행 결과·페어 기여·교대 시간은 현장에서 직접 기록한다.
예시를 복사하는 대신 자신이 해결한 오류 1건과 변경 전후 근거를 적게 한다.

한계: 메모리 저장이므로 프로그램 종료 후 자료가 사라진다. 실제 AI Agent 실행·파일 저장·사용자 인증은 구현하지 않았다.

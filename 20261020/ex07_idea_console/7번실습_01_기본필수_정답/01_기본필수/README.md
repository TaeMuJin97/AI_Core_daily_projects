# 실습 07 · 아이디어 이름 등록·조회 콘솔 · 기본필수

기준: Day2 PPT **63쪽** / 교안 실습 시간 **45분**(세 난이도를 모두 수행하는 합계가 아니라 해당 실습 블록의 시간)

## 학습 목표와 완료 기준

1. 메뉴 반복·등록·전체 목록·종료를 구현한다. 아이디어 이름은 List[str]에 저장한다.
2. 빈 이름은 저장하지 않는다. 중복 검사·검색·Dict·난이도·Agent 역할 저장은 다음 난이도의 기능이다.
3. 최소 3개의 아이디어를 등록한 결과, 빈 목록, 잘못된 명령, 종료를 점검한다.
4. 제출_보고서.md에 요구사항 4개·데이터 예시 3건·함수 표·테스트 3건 이상·페어 피드백을 작성한다.

## 작업 순서

먼저 입력·처리·출력을 메모한 뒤 작은 단계 하나를 작성하고 바로 실행합니다.
코드의 해설 번호와 수강생 TODO 번호가 대응합니다. 정답을 먼저 읽어 주기보다 입력값과 기대 결과를 질문합니다.

1. 공백 정리 후 빈 이름을 거부하고 아이디어 이름을 List에 저장하세요.
2. 빈 목록과 번호가 붙은 전체 목록을 문자열로 반환하세요.
3. add_idea를 호출하고 반환값에 따라 안내하세요.
4. format_ideas의 결과를 화면에 출력하세요.

## 실행 방법

VS Code에서 **강사용 폴더 자체**를 열고 터미널에서 실행합니다. `.venv`를 활성화했거나 VS Code 실행기로 선택한 상태를 전제로 합니다.

```powershell
python "ex07_idea_console/01_기본필수/main.py"
```

또는 이 README가 있는 폴더로 이동하여 `python main.py`을 실행합니다.
활성화에 문제가 있으면 역할 폴더 기준 `.\.venv\Scripts\python.exe`를 `python` 대신 사용합니다.
소스 파일을 압축파일 안에서 직접 실행하지 말고 먼저 압축을 풉니다.

## 예시 입력

아래 줄을 위에서부터 **한 줄씩** 입력합니다. 프롬프트 자체는 입력하지 않습니다.

```text
1
StudyBot
1
PaperMate
1
DataHelper
2
0
```

`sample_input.txt`는 같은 입력을 담고 있으며 프로그램이 파일을 읽는 실습이 아닙니다.
`expected_output.txt`는 프로그램 stdout 원문입니다. 자동 입력에서는 타이핑한 내용이 화면에 되비치지 않아 프롬프트들이 한 줄에 이어질 수 있습니다.
`실행예.txt`에는 사람이 키보드로 입력했을 때와 같은 대화형 예시를 실었습니다.

## 핵심 문법

PPT 63쪽의 기본필수 완료 기준을 따른다. 소개 슬라이드의 검색·통계는 전체 프로젝트의 확장 목표이며 기본필수에 강제하지 않는다.

```powershell

```

실행 결과·반환값·경계값 일부를 점검하지만 모든 가능한 오류를 증명하거나 설명·협업 점수를 자동 채점하지는 않습니다.
강사용 정답은 전체 자동 검사를 통과해야 합니다.

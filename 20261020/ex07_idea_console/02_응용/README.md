# 실습 07 · Dict 기반 검색·필터·중복·통계 · 응용

기준: Day2 PPT **63쪽** / 교안 실습 시간 **45분**(세 난이도를 모두 수행하는 합계가 아니라 해당 실습 블록의 시간)

## 학습 목표와 완료 기준

1. List[Dict]를 사용한다. 각 Dict는 name·problem·roles·difficulty 키를 가진다.
2. 등록·목록·키워드 검색·난이도 필터·난이도별 통계·종료를 제공한다. 통계는 PPT 62쪽의 공통 기능을 구체화한 것이다.
3. 난이도는 기본필수·응용·심화만 허용한다. 프로젝트명 중복은 앞뒤 공백과 대소문자를 무시하여 판단한다.
4. 검색은 프로젝트명·문제·역할을 대상으로 대소문자를 구분하지 않는 부분 일치이다. 빈 검색어는 거부한다.
5. 등록 실패 시 데이터를 일부라도 저장하지 않는다. 검색·필터는 원본 List를 변경하지 않는다.
6. 최소 3개의 데이터 예시와 3건 이상의 정상·경계 테스트를 기록한다. 입력/출력과 기능 처리 함수를 구분한다.
7. 기본필수는 최소 기능, 응용·심화는 확장 기능을 평가한다. 파일 저장·클래스·API 호출은 오늘의 필수가 아니다.
8. 응용 단계의 roles는 문자열이다. 예: Researcher. 여러 역할의 구조화는 심화에서 수행한다.

## 실행 방법

VS Code에서 **수강생용 폴더 자체**를 열고 터미널에서 실행합니다. `.venv`를 활성화했거나 VS Code 실행기로 선택한 상태를 전제로 합니다.

```powershell
python "ex07_idea_console/02_응용/main.py"
```

또는 이 README가 있는 폴더로 이동하여 `python main.py`을 실행합니다.
활성화에 문제가 있으면 역할 폴더 기준 `.\.venv\Scripts\python.exe`를 `python` 대신 사용합니다.
소스 파일을 압축파일 안에서 직접 실행하지 말고 먼저 압축을 풉니다.

## 자동 확인 (선택)

역할 폴더 루트에서 실행합니다.

```powershell
python tools/check.py --exercise 07 --level applied
```

검사 도구는 이미 작성된 보조 프로그램이며 오늘 구현해야 할 과제가 아닙니다.
실행 결과·반환값·경계값 일부를 점검하지만 모든 가능한 오류를 증명하거나 설명·협업 점수를 자동 채점하지는 않습니다.
미완성 상태에서 FAIL이 나오는 것은 정상입니다. PASS만 만들려고 결과를 상수로 출력하지 말고 요구사항의 일반 규칙을 구현합니다.

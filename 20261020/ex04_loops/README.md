# 실습 04 · 반복문과 컬렉션 순회

PPT 45쪽, 35분 블록입니다. 기본필수에서 출발하여 응용·심화로 확장합니다.
각 단계는 독립 실행되며 다른 폴더의 정답 파일을 불러오지 않습니다.

| 단계 | 활동 | 코드 |
|---|---|---|
| 기본필수 | 1부터 N까지 누적하기 | `01_기본필수/main.py` |
| 응용 | 평균 80점 이상 수강생 번호 매기기 | `02_응용/main.py` |
| 심화 | while 메뉴와 작업 List | `03_심화/main.py` |

세부 지시·완료 기준·실행 예는 각 단계 폴더의 README.md를 확인합니다.

# 실습 04 · while 메뉴와 작업 List · 심화

기준: Day2 PPT **45쪽** / 교안 실습 시간 **35분**(세 난이도를 모두 수행하는 합계가 아니라 해당 실습 블록의 시간)

## 학습 목표와 완료 기준

1. 1=추가, 2=목록, 0=종료를 반복하는 메뉴를 만든다.
2. 잘못된 명령은 다시 입력받는다. 빈 항목은 저장하지 않는다.
3. 이 단계에서는 동일한 항목의 중복 저장을 허용한다. 함수로 분리하는 작업은 실습 05 심화에서 수행한다.

## 작업 순서

먼저 입력·처리·출력을 메모한 뒤 작은 단계 하나를 작성하고 바로 실행합니다.
TODO 표시가 있는 부분만 우선 완성합니다. 0·빈 문자열·pass는 답이 아니라 임시 값입니다. NotImplementedError가 나오면 표시된 함수를 구현합니다.

1. 빈 항목을 거부하고 유효한 항목은 List 끝에 추가하세요.
2. 빈 목록을 처리하고 항목이 있으면 번호와 함께 출력하세요.
3. 잘못된 명령을 안내한 뒤 다시 입력받게 하세요.

## 실행 방법

VS Code에서 **수강생용 폴더 자체**를 열고 터미널에서 실행합니다. `.venv`를 활성화했거나 VS Code 실행기로 선택한 상태를 전제로 합니다.

```powershell
python "ex04_loops/03_심화/main.py"
```

또는 이 README가 있는 폴더로 이동하여 `python main.py`을 실행합니다.
활성화에 문제가 있으면 역할 폴더 기준 `.\.venv\Scripts\python.exe`를 `python` 대신 사용합니다.
소스 파일을 압축파일 안에서 직접 실행하지 말고 먼저 압축을 풉니다.

## 예시 입력

아래 줄을 위에서부터 **한 줄씩** 입력합니다. 프롬프트 자체는 입력하지 않습니다.

```text
1
Python
1
Git
2
9
0
```

`sample_input.txt`는 같은 입력을 담고 있으며 프로그램이 파일을 읽는 실습이 아닙니다.
`expected_output.txt`는 프로그램 stdout 원문입니다. 자동 입력에서는 타이핑한 내용이 화면에 되비치지 않아 프롬프트들이 한 줄에 이어질 수 있습니다.
`실행예.txt`에는 사람이 키보드로 입력했을 때와 같은 대화형 예시를 실었습니다.

## 핵심 문법

종료 경로는 제공되어 있다. 자료를 초기화하는 items=[]를 while 안으로 이동하지 않는다.

## 자동 확인 (선택)

역할 폴더 루트에서 실행합니다.

```powershell
python tools/check.py --exercise 04 --level advanced
```

검사 도구는 이미 작성된 보조 프로그램이며 오늘 구현해야 할 과제가 아닙니다.
실행 결과·반환값·경계값 일부를 점검하지만 모든 가능한 오류를 증명하거나 설명·협업 점수를 자동 채점하지는 않습니다.
미완성 상태에서 FAIL이 나오는 것은 정상입니다. PASS만 만들려고 결과를 상수로 출력하지 말고 요구사항의 일반 규칙을 구현합니다.
